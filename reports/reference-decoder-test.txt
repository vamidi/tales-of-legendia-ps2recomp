does, with the same engine.  The question is whether the nine-byte block
this decoder reads is on the disc, and it is not: this disc's envelope is
a sixteen-byte CPS header with no method byte for the scanner to anchor
on.  So the expected answer below is zero, and a zero is only worth
printing next to a control that is not zero.
